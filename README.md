## 🌟 Quelques projets

- 🤖 **A.R.I.A - Agent ReAct pour audits de sécurité**
Assistant de pentest local fondé sur LangChain et une boucle ReAct. Architecture modulaire (agent, tools, app) avec recherche CVE via l’API NVD, contextualisation OWASP et vérification Metasploit en lecture seule. Génère des rapports Markdown/PDF et a été évalué sur 5 scénarios critiques (SQLi, XSS, RCE, LFI, SSRF).  
<a href="https://github.com/Ethanbst/ARIA_penest_agent">Voir le dépôt GitHub</a>

- ⚙️ Serveur Domestique IoT sous Ubuntu 24.04 LTS  
Projet de serveur domestique sur un Lenovo IdeaPad 320-15ABR : passerelle réseau, DHCP/DNS (dnsmasq) et domotique Home Assistant. Pont entre WiFi étudiant et réseau IoT, accès distant sécurisé via Tailscale, pare-feu UFW + Fail2ban. Automatisations (lumières, routines, Spotify), intégrations Alexa/Meross/Tuya. Stack : Docker, SSH durci, scripts de maintenance.

- 🌐 **Site Web de la Communauté de Communes du Sud-Avesnois** *(Stage - Avr/Juin 2025)*  
  Refonte complète du site institutionnel sous Django (RGAA 4.1) : BDD relationnelle, back-office CRUD avec gestion des droits, architecture MVC, formulaires sécurisés.  
  <a href="https://github.com/Ethanbst/CCSA_Public">Voir le dépôt GitHub</a> | <a href="https://www.cc-sudavesnois.fr">Voir le site web</a>

- 🎮 **Jeu 2D rétro (C / SDL2)**
